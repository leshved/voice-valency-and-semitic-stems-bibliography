# Bibliographic Database on Voice, Valency, and Semitic Verbal Stems
A bibliographic database on voice, valency-changing operations, argument structure, and Semitic verbal stems.
This repository contains a bibliographic database compiled as part of my dissertation project on verbal stems and causativization in Christian Urmi Neo-Aramaic.

The database brings together references on two related topics:

1. voice, valency-changing operations, causatives, anticausatives, lability, and argument structure;
2. Semitic verbal stems, with a special focus on Aramaic and Neo-Aramaic verbal morphology.

The database is intended as a research aid for linguists working on voice, valency, argument structure, Semitic morphology, and Neo-Aramaic languages.

## Files

- `Shvedova_2026_bibliography.xlsx` — the full database in Excel format, with separate sheets for the two main thematic sections.
- `voice_valency_bibliography.csv` — references on voice, valency-changing operations, causatives, anticausatives, lability, and argument structure.
- `semitic_verbal_stems_bibliography.csv` — references on Semitic verbal stems and related issues in Semitic morphology.

## Scope

The database includes bibliographic metadata for books, edited volumes, journal articles, book chapters, dissertations, and other scholarly works. Depending on the entry, the following information may be provided:

- category;
- author(s);
- year of publication;
- title;
- publication venue;
- volume, issue, and page numbers;
- DOI or URL;
- language(s) discussed;
- thematic labels;
- abstract;
- short notes.

The database is not intended to be exhaustive. It reflects the literature collected for a dissertation project and will be updated when new references are added or existing entries are corrected.
